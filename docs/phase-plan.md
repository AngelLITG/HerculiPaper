# Phase Plan

This document tracks the phased roadmap for HerculiPaper.

- Phase 1: ShreddedPaper Multithreading foundations (region locks, schedulers, chunk/entity/network scaffolding, instrumentation).
- Phase 2: Public API extensions and compat shims.
- Phase 3: MultiPaper (multi-server) integration and state sync.

Refer to `todo-tasks.txt` for the authoritative active task list.
